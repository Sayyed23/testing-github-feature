# Next.js App

This directory contains a standard Next.js project structure created to demonstrate the `npx create-next-app@latest` command.

## Terminal Command to Create Locally

```bash
npx create-next-app@latest nextjs-app --typescript --tailwind --eslint --app
```

This command creates a Next.js app with:
- TypeScript
- Tailwind CSS
- ESLint
- App Router

## To Run

1. `cd nextjs-app`
2. `npm install`
3. `npm run dev`

Visit `http://localhost:3000`
