## Next.js Project Structure

A complete Next.js project structure has been added in the `nextjs-app/` directory.

### Terminal Command to Create Locally
```bash
npx create-next-app@latest nextjs-app --typescript --tailwind --eslint --app
```

This replicates the structure with:
- TypeScript
- Tailwind CSS
- ESLint
- App Router (`app/` directory)
